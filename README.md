# FuzzyCare – Smart Patient Health Risk Assessment System

## Overview
FuzzyCare is a patient health risk assessment system developed using a **Mamdani Fuzzy Inference System**. It analyzes patient health parameters using fuzzy logic and estimates potential health risk levels through rule-based reasoning.

## Features
- Patient health parameter analysis.
- Mamdani Fuzzy Inference System.
- Fuzzy membership functions.
- 12 Fuzzy IF-THEN rules.
- Health risk assessment.
- Interactive Streamlit dashboard.

## Technologies Used
- Python
- Streamlit
- Plotly
- Fuzzy Logic

## Run Locally

Clone the repository:

```bash
git clone https://github.com/Elgabinu/FuzzyCare.git
cd FuzzyCare
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
